## How the queue publishes itself

See [scheduled publishing](./scheduled-publishing.md). Short version: each post
goes into `blog_posts` with `status = 'scheduled'` and a `publish_at`, fully
written and carded. A Vercel Cron hits `/api/cron/publish-post` at 07:30 and
18:30, and each run takes the oldest post that is due, dates it today, flips it
live, revalidates and pings IndexNow. One post per run, so two a day, and a
missed run drains the queue slightly later rather than dumping the backlog on
one date.
